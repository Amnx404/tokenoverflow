## Boundary and interpretation

One canonical health GET, one OLD known community-detail GET, then official client 2.4.0 initialize/initialized notification and one empty default-community search. Only the SDK may initiate one incidental listening GET. Budget is normally five or six HTTP attempts, maximum six, no DELETE, retries, tools/list, discovery, detail tool call, extra query, metadata alias or fallback. The listener's observed 405 is distinct from logical search success. An attempted but locally aborted/unobserved listener has null status and terminal package UNKNOWN/partial, never PASS or an inferred405; an absent listener is allowed. SDK close behavior must be inspected against the provisioned pinned client before any production GO; client.close is used, never terminateSession. A rejected duplicate attempt never reaches fetch.

Manual REST requires generated UUID, JSON and no-store. SDK correlation IDs are validated UUID-or-null and not mandatory; response status/no-store remain checked. Health exact ok/200 is PASS evidence; exact degraded/503 is DEGRADED. Missing target is TARGET_ABSENT, separate from SERVICE_UNAVAILABLE/5xx. No historical search/fix/result count is an oracle: actual coarse counts are retained. Unexpected shape/privacy/trust/parity fails with fixed codes. No raw error messages/stacks, headers, URLs, RPC arguments, author names, report text or body content enter diagnostics. Bounded response bytes are parsed only in memory and discarded, with no raw-body/full-content retention or equality claim. Generated request IDs and UTC/header elapsed metadata are private correlation, not people, trend, full-body timing or adoption evidence.

Boundaries: 1 MiB per response, 20s per fetch including body, 15s SDK connect/call, 60s overall fetch abort. Dispatch UTC is immediately before fetch; headers UTC and bounded monotonic elapsed measure headers only. Bodies/status/flags are recorded safely before assertions; result is retained on failure without retry. Client close is attempted in finally; only observed closure is attested. This is a finite CLI, not a service or generic framework.
